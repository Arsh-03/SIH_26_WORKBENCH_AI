## 1. System Overview & Problem Statement Context

* **Problem Statement (PS26117):** Sovereign On-Premise Agentic AI Workbench for Confidential Industrial Work.
* **Core Mandate:** Total data sovereignty, zero external egress, strict air-gapped readiness, multimodal comprehension (technical specs, blueprints, sensor logs), and verifiable agentic tool calling.
* **Host Runtime:** Workstation/local private node running Ollama/vLLM, FastAPI, ChromaDB/Qdrant, and isolated Docker/subprocess sandbox containers.

## 4. Complete End-to-End Workflows

### Flow 1: Document Ingestion & Local Embedding
1. **Upload:** User drops an industrial file on the canvas (`POST /api/v1/workspaces/{id}/documents/upload`).
2. **Storage:** Gateway saves the raw file to `storage/uploads/{workspace_id}/`.
3. **Extraction:** Backend executes `PyMuPDF` or `Surya OCR` to extract clean Markdown and tabular representations.
4. **Chunking:** Text is split using recursive semantic chunking into 512-token segments with a 50-token overlap.
5. **Vectorization:** Gateway batches segments to local Ollama via `POST /api/embeddings` (`nomic-embed-text`).
6. **Persistence:** Vectors and metadata are committed to local ChromaDB collections; metadata is saved to SQLite.

### Flow 2: Bilateral Agent Execution Loop
1. **Connect:** Frontend establishes real-time connection (`WS /api/v1/agents/ws/{session_id}`).
2. **Prompt:** User sends a query with active document context and allowed tool list.
3. **Reasoning:** Backend formats the prompt with JSON function schemas and calls `Qwen 2.5`.
4. **Tool Call (`thought` / `tool_call`):** Model determines external data is required and emits a function call.
5. **Execution (`tool_result`):** Backend invokes the local tool (ChromaDB search or Sandbox Python execution).
6. **Reflection:** Tool output is formatted and fed back into the model context.
7. **Synthesis (`final_answer`):** Model concludes the task, producing verified citations with document chunk references.

### Flow 3: Multimodal Blueprint & Schematic Vision Pipeline
1. **Inspection Request:** User highlights an image or CAD render on canvas (`POST /api/v1/vision/analyze`).
2. **Pre-Processing:** Image is normalized, converted to base64, and bundled with visual bounding box instructions.
3. **VLM Inference:** Payload is processed locally by `Qwen 2-VL`.
4. **Spatial Parsing:** Model outputs normalized coordinates for valves, pumps, pipe tags, and detected hazards.
5. **Canvas Rendering:** Frontend renders vector bounding box annotations directly over the canvas image node.

### Flow 4: Air-Gapped Code Sandbox Execution
1. **Script Dispatch:** Agent generates a Python simulation or plotting script (`POST /api/v1/sandbox/execute`).
2. **Isolation Enforcement:** Script runs in a sandboxed Docker container initialized with:
   * `--network none` (Hard physical network block)
   * `--memory 512m` (Memory ceiling)
   * `--cpus 1.0` (Compute quota)
   * 10-second timeout killer
3. **Artifact Generation:** Matplotlib plots or CSV outputs are written to `/storage/artifacts/`.
4. **Result Delivery:** Gateway captures `stdout`, `stderr`, and artifact file URLs, passing them back to the agent.

### Flow 5: Zero-Egress Audit & Compliance Assurance
1. **Interception:** FastAPI custom middleware traps every incoming request and outgoing model payload.
2. **Socket Inspection:** Middleware checks internal routing tables to guarantee zero outbound IP requests to public networks.
3. **Audit Record:** A cryptographically signed trace is written to SQLite logging query hashes, tools executed, files accessed, and egress verification status.

## 5. API Endpoint Specifications & Data Contracts

### 5.1 Document Ingestion & Management

#### `POST /api/v1/workspaces/{workspace_id}/documents/upload`
Uploads and indexes industrial documents for vector retrieval.

* **Headers:** `Content-Type: multipart/form-data`
* **Path Parameters:**
  * `workspace_id` (string): Target workspace identifier.
* **Form Data:**
  * `file`: Binary file (PDF, PNG, JPG, DXF, CSV).
  * `doc_type`: String (`manual` | `blueprint` | `telemetry` | `spec_sheet`).
  * `classification`: String (`confidential` | `restricted` | `internal`).

* **Response (`202 Accepted`):**
```json
{
  "document_id": "doc_9f8a3c21",
  "workspace_id": "ws_alpha_01",
  "filename": "boiler_pressure_manual.pdf",
  "file_size_bytes": 2097152,
  "status": "queued",
  "estimated_chunks": 36,
  "created_at": "2026-09-01T13:50:00Z"
}
```

#### `GET /api/v1/workspaces/{workspace_id}/documents/{document_id}/status`
Retrieves ingestion and indexing status for a given document.

* **Response (`200 OK`):**
```json
{
  "document_id": "doc_9f8a3c21",
  "workspace_id": "ws_alpha_01",
  "status": "indexed",
  "total_pages": 12,
  "total_chunks": 36,
  "embedding_model": "nomic-embed-text",
  "vector_dimensions": 768,
  "completed_at": "2026-09-01T13:50:14Z"
}
```

## 6. Local Relational Storage Schema (SQLite DDL)

```sql
-- Workspaces containing documents and sessions
CREATE TABLE workspaces (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Master Document Records
CREATE TABLE documents (
    id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
    filename TEXT NOT NULL,
    filepath TEXT NOT NULL,
    file_type TEXT NOT NULL,
    classification TEXT NOT NULL,
    chunk_count INTEGER DEFAULT 0,
    status TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Chunk Registry mapped to ChromaDB/Qdrant Vector IDs
CREATE TABLE document_chunks (
    id TEXT PRIMARY KEY,
    document_id TEXT NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    chunk_index INTEGER NOT NULL,
    page_number INTEGER,
    raw_content TEXT NOT NULL,
    vector_id TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Real-time Agent Canvas Sessions
CREATE TABLE agent_sessions (
    id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL REFERENCES workspaces(id) ON DELETE CASCADE,
    title TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Air-Gap Verification & Execution Audit Trail
CREATE TABLE audit_logs (
    id TEXT PRIMARY KEY,
    session_id TEXT REFERENCES agent_sessions(id),
    prompt_hash TEXT NOT NULL,
    tools_called TEXT NOT NULL,
    citations TEXT NOT NULL,
    egress_bytes INTEGER DEFAULT 0,
    execution_duration_ms INTEGER NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 7. Python Pydantic Data Models (FastAPI Implementation Layer)

```python
from pydantic import BaseModel, Field
from typing import List, Optional

# Document Ingestion Models
class DocumentUploadResponse(BaseModel):
    document_id: str
    workspace_id: str
    filename: str
    file_size_bytes: int
    status: str
    estimated_chunks: int
    created_at: str

class DocumentStatusResponse(BaseModel):
    document_id: str
    workspace_id: str
    status: str
    total_pages: int
    total_chunks: int
    embedding_model: str
    vector_dimensions: int
    completed_at: str

# WebSocket Agent Execution Models
class AgentRunRequest(BaseModel):
    action: str = "run_agent"
    workspace_id: str
    prompt: str
    active_document_ids: List[str] = Field(default_factory=list)
    allowed_tools: List[str] = Field(default_factory=list)
    temperature: float = 0.2

class ChunkCitation(BaseModel):
    document_id: str
    chunk_id: str
    page_number: int
    snippet: str

class AgentFinalResponse(BaseModel):
    event: str = "final_answer"
    step: int
    content: str
    citations: List[ChunkCitation]
    metrics: dict

# Vision Pipeline Models
class VisionAnalysisRequest(BaseModel):
    workspace_id: str
    image_path: str
    prompt: str
    confidence_threshold: float = 0.70

class DetectedElement(BaseModel):
    element_id: str
    label: str
    tag_code: Optional[str] = None
    bounding_box_2d: List[int]  # [ymin, xmin, ymax, xmax]
    confidence: float

class VisionAnalysisResponse(BaseModel):
    model: str
    detected_elements: List[DetectedElement]
    image_dimensions: dict
    processing_time_ms: int

# Sandbox Execution Models
class SandboxExecuteRequest(BaseModel):
    code: str
    language: str = "python"
    timeout_seconds: int = 10
    memory_limit_mb: int = 512

class GeneratedArtifact(BaseModel):
    filename: str
    download_url: str

class SandboxExecuteResponse(BaseModel):
    exit_code: int
    stdout: str
    stderr: str
    execution_time_ms: int
    generated_artifacts: List[GeneratedArtifact]
    limits_exceeded: bool

# Audit Models
class AuditTraceRecord(BaseModel):
    trace_id: str
    session_id: str
    timestamp: str
    user_prompt_hash: str
    tools_invoked: List[str]
    retrieved_chunk_citations: List[str]
    external_egress_bytes: int = 0
    compliance_status: str
```
